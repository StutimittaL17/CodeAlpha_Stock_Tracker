# 📈 Stock Portfolio Tracker

## 📖 Description

This is a simple Python-based Stock Portfolio Tracker that allows users to calculate their total investment based on stock names and quantities entered manually. The program uses predefined stock prices and computes the total value of the portfolio.

## 🚀 Features

* User input for stock names and quantity
* Predefined stock price dictionary
* Calculates total investment value
* Saves result to a file (optional)

## ▶️ How to Run

```bash
python stock_tracker.py
```

## 🛠️ Technologies Used

* Python
* File Handling
